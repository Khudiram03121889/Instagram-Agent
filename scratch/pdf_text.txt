SECTION 1 — DIAGNOSIS: What Is Wrong Right Now
Understanding the gap before we fix it
1.1 Documentary vs. Friendly — The Core Gap
Both examples below are exactly 9 words and cover the same science topic (boredom). One sounds like a BBC
documentary. One sounds like a friend. Only one connects with a real audience.
CURRENT OUTPUT (Documentary Style)
TARGET OUTPUT (Friendly Style)
• "Your mind feels adrift, a vast internal void."
• "You know that bored feeling when nothing seems
interesting?"
• "Its default network ignites, searching for new
input."
• "Your brain actually hates that. It starts searching
— fast."
• "That preparation means boredom is not empty."
• "So boredom? It is your brain quietly preparing
you."
• Uses words: vast, void, adrift, ignites, default
network
• Uses words: you, your, know, actually, quietly,
preparing
• Who talks like this? Nobody. It creates distance.
• This is how a friend explains something over chai.
1.2 The 4 Root Causes
1
Language Too Compressed &
Academic
The 15-word limit forces the LLM to delete natural human phrases
like 'You know when...' or 'Think about it...' and replace them with
dense formal words. Result: sounds like Wikipedia being read
aloud, not a person talking.
2
Hook Formula Misses the Lived
Moment
Current hooks are: Personal Attack, Impossible Claim, Scale Shock.
These are intellectually clever but emotionally cold. The viewer has
never experienced a 'scale shock'. They have experienced
boredom, forgetting a name, feeling warm after rubbing hands.
TYPE D (Daily Moment hook) is missing.
3
Topics Are Research Paper Titles
Topics like 'Why entropy always increases' or 'Why the future
affects the past at quantum scale' have no human entry point. A
normal viewer cannot relate to them. They need to be reframed as
daily life questions before the agent sees them.
4
Bridge Openers Are Too Generic
The current bridge rule says use templates like 'To understand
that...' — but the Gemini free model often uses them without filling
in the specific concept. Result: 'To understand that, we must...'
which adds zero value and breaks continuity.

CHANGE 4 — Add the Story Rule to Tasks
File: config/tasks.yaml
FILE: config/tasks.yaml
This file defines what each agent is asked to do per task. The write_script_task needs one new rule block added at the top of
its description.
What to Add — The Story Rule Block
In tasks.yaml, find the 'write_script_task' section. Find the line that starts with 'HARD REQUIREMENTS:'. BEFORE
that line, add this new block:
THE STORY RULE (Add BEFORE 'HARD REQUIREMENTS'):
These 5 clips are ONE SINGLE STORY, not 5 separate facts.
Think of it like a 40-second mini-movie with a beginning, middle, and end.
Clip 1 — Opens the story from a real human experience or feeling.
Clip 2 — Raises the question: 'But why does this happen?'
Clip 3 — Gives the simple scientific reason in plain English.
Clip 4 — Shows the surprising or meaningful side of that reason.
Clip 5 — Brings it back to the viewer personally. Makes it real for them.
STORY TEST (run this before finalizing the script):
If someone watches only Clip 3 out of context — do they feel lost?
If yes — the story is connected. Good.
If no — the clips are too independent. Rewrite the bridges.
LANGUAGE TEST (run this before finalizing):
Read the script aloud. Does it sound like a real person talking?
If it sounds like reading a textbook — it is wrong. Rewrite.
Target: A 14-year-old listening should understand every single word.
What to Add — Human Translation Step
In the write_script_task description, find the 'STYLE:' block. After the STYLE block, add this:
HUMAN TRANSLATION STEP (Add after STYLE block):
Before writing any clip, complete this internal step:
Ask yourself: 'What does this topic feel like in daily life?'
Topic: 'Why entropy always increases'
Human Translation: 'Why your room gets messy but never cleans itself'
Topic: 'Why friction creates heat'
Human Translation: 'Why rubbing your hands makes them warm'
Topic: 'Why time moves slower near gravity'
Human Translation: 'Why time moves faster for your head than your feet'
This human translation MUST appear somewhere in Clip 1 or Clip 2.

SECTION 4 — TESTING CHECKLIST

How to Test That the Changes Are Working
After making all 4 changes, run the agent on ONE topic from the new list. Then check the generated script against
this checklist before doing anything else.
CLIP 1 CHECK
Does Clip 1 start from a daily human experience or feeling?
Action:
If it starts with a definition, a fact, or an abstract concept — FAIL. The Type D (Daily Moment) hook is
mandatory. Rerun the agent.
WORD CHECK
Are any banned words present? (vast, void, adrift, immense, phenomenon, resonance)
Action:
Search the script for each banned word. If any appear — the validator did not catch it. Manually
rewrite that clip.
YOU/YOUR CHECK
Does 'you' or 'your' appear in at least 3 of the 5 clips?
Action:
Count 'you' and 'your' across all 5 clips. If under 3 clips — the script is too cold and disconnected.
Rerun.
READ ALOUD
CHECK
Read the full script aloud. Does it sound like a real person talking?
Action:
If it sounds robotic, stiff, or like a textbook — it is wrong. Identify the stiff clip and check which banned
words crept in.
14-YEAR-OLD
CHECK
Would a 14-year-old understand every single word without a dictionary?
Action:
Go word by word in each clip. Any word a 14-year-old would not know must be followed by a plain
English explanation in the same clip.
STORY FLOW
CHECK
Do all 5 clips feel like one continuous story?
Action:
Read Clip 3 alone. If it makes complete sense without Clips 1-2 — the bridges are too weak.
Strengthen the bridge openers.
WORD COUNT
CHECK
Is every clip within the 15-word limit?
Action:
Count words in each clip manually. Clip limits: Clip1=14, Clip2=13, Clip3=13, Clip4=15, Clip5=14. If
over — trim to exact limit.
